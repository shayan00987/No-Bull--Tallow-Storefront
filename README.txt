NO BULL TALLOW — COMPLETE STATIC STOREFRONT CONCEPT

UPLOAD STRUCTURE
Upload the CONTENTS of this folder to the ROOT of your GitHub repository (not the enclosing download folder). The root should contain index.html, styles.css, script.js, README.txt, CATALOG_REVIEW.txt, and the assets/ folder.

FILES
- index.html: page structure, hero, sections, footer, bag drawer
- styles.css: responsive warm-white and brown theme
- script.js: seven sample product cards, search, category filter and front-end bag
- assets/logo/logo.svg: concept wordmark
- assets/icons/: favicon and UI icons
- assets/ai-products/: generated concept product imagery
- assets/product-placeholder.svg: local fallback

IMPORTANT
This is a static storefront concept, not the official No Bull Tallow site. AI product images are illustrative concepts and are not authentic product/packaging photos. Confirm product names, prices, ingredients, stock and links with the official store before publishing commercially. The displayed CAD prices are starter values and may not match current listings. Product buttons lead to the official store homepage or known listing; customers must build their cart again there.

PAYMENTS
This package does not collect payment details or process payments. Live checkout requires store-owner authorization and a secure Shopify/payment integration with verified product variants, tax and shipping setup. Never put secret API keys in browser JavaScript.

GITHUB PAGES
1. Download and extract the ZIP.
2. Open the extracted folder.
3. Upload its contents (index.html etc. and assets/) to the repository root. Do not upload only the outer folder.
4. If GitHub asks, replace the existing same-named files.
5. Commit to the branch configured in Settings > Pages (commonly main).
6. Wait for the Pages deployment to finish, then refresh the site in a private tab.

ASSET PATHS
All custom assets use relative paths such as assets/logo/logo.svg. Keep the assets folder alongside index.html. Filenames are case-sensitive on GitHub Pages.
